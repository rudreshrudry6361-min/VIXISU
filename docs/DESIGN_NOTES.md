# Design review and implementation rationale

## Inspiration

**GARUDA 2026 (OFFWG)** — The accessible site content describes a scroll-led poster carousel, a grid/carousel toggle, drag/scroll exploration, and a locker-room journey. VIXISU adapts the *principles* of cinematic entry, editorial hierarchy, interactive discovery and story-like sequencing without reusing original content.

**Orano Innovation Experience** — The project agency's published description emphasizes immersive interactive design, stylized wireframe representation, 3D/motion and gamified exploration. VIXISU adopts subtle orbital/wireframe geometry, animated sport illustrations and purposeful microinteractions rather than attempting to clone the site's assets or behavior.

## Visual system

- Near-black evergreen background, layered glass/dark surfaces, electric lime accents and warm amber for cricket.
- Oversized editorial headings, uppercase micro-labels, narrow tracking and large whitespace.
- Original SVG cricket and football athlete illustrations; no borrowed imagery.
- Hero orbit, grid overlays, lightweight floating illustration and restrained hover transitions.
- Product pages prioritize information architecture and accessibility over heavy animation.
- Reduced-motion media query and responsive mobile navigation.

## Limitations of reference review

The GARUDA page's public content was available, but the Orano experience did not expose readable page text in the web fetch. Orano interaction descriptions were corroborated using the agency's published case study. The implementation is an original design interpretation, not a pixel-perfect reproduction.
