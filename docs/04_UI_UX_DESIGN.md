# UI and UX design brief

Use vintage ivory `#E9E6D8`, forest `#355B42`, ink `#17251C`, electric lime `#E5F34B` and rust `#A1492B`. Set oversized condensed display type against readable sans-serif copy and tabular metrics. Use the light editorial palette for scouting screens and reserve dark photographic compositions for the entrance and player art.

The landing sequence combines full-screen licensed photography, an interactive numbered comic-poster collection and a locker-room-inspired entrance. Give the gallery rail and grid modes, an expandable player artwork view and controls for mouse, touch and keyboard. Use cinematically paced transitions and optional perspective where motion provides feedback. Keep controls available without animation. Respect system reduced-motion settings.

Transform licensed photographs of the identified player with ink outlines, flat colors and halftone texture. Keep source, photographer, license and modification credits with the artwork. When a portrait is unavailable, use a typographic player card.

The scouting room emphasizes cohort controls, score provenance and evidence. Prioritize visible filters and accessible tables. Charts need equivalent numeric values and units. Unavailable metrics should have a readable status.

References for gallery pacing and selective 3D include [GARUDA 2026](https://garuda2026.offwg.com/home) and [Orano Innovation](https://www.orano.group/experience/innovation/en).
